# Работа с репозиторием

- Проект: Python 3.11+, aiogram 3, SQLite. Запуск: `gradebot run`; настройки: `.env` по образцу `.env.example`.
- Не открывайте и не выводите в логи `.env`, токены, ФИО, оценки и содержимое реальной БД.
- Рабочие файлы SQLite находятся в `instance/`. Каталог игнорируется Git, кроме `.gitkeep`. Не переносите БД при запущенном боте: используйте `database_run_lock` и миграцию из `gradebot/runtime.py`.
- Обработчики в `gradebot/bot.py` не должны содержать SQL или прямых обращений к `db.conn`. Добавляйте методы чтения и транзакционные операции в `gradebot/db.py`; изменение схемы — в `gradebot/schema.py`.
- Пользовательские реплики редактируйте в `gradebot/messages.toml`. Подставляйте значения через `MessageCatalog.render`: он экранирует HTML. Для осознанной разметки используйте `TrustedHtml`; при отправке HTML указывайте `parse_mode="HTML"`.
- Для новых функций пишите аннотации типов и короткие docstring’и. Комментарии нужны для неочевидных ограничений, особенно транзакций, повторной доставки и структуры Google Sheets.
- Перед коммитом запускайте `.venv/bin/ruff check gradebot tests` и `.venv/bin/pytest -q`. Сетевые тесты используют только loopback, но в песочнице могут потребовать разрешения на сокеты.
- Сохраняйте уже существующие незакоммиченные правки; не перезаписывайте их без проверки diff.

## Терминология интерфейса и данных

- **Таблица** — один файл Google Sheets. В БД это `workbooks`: собственный ID, название и URL файла. В `/addtab` и `/removetable` выбирают ID таблицы.
- **Лист** — вкладка внутри таблицы. В БД это `sheets`: собственный ID, `workbook_id`, `tab_name`, URL вкладки и настройки оценок. В `/subject`, `/columns` и `/remove` выбирают ID листа.
- В сообщениях называйте сущность по фактическому действию: обновление, оценка, настройка и удаление одного листа — «лист»; действия над всем Google-файлом и всеми его листами — «таблица». Счётчики обновления считают листы. Не называйте ID листа ID таблицы и наоборот.
- Удаление последнего листа оставляет пустую таблицу до отдельного подтверждения. Пустую таблицу можно сохранить для `/addtab`; `/removetable` удаляет таблицу и все её листы после подтверждения.
